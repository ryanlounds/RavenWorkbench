Raven Workbench Instructions

Standard operating procedures for FRC Team 1310 CAD version control, locking, and production release.

1. File Explorer & Part Inspection

Navigate subsystem folders in Designs. Single-click any CAD file to inspect its live 3D quick-preview and metadata; double-click (or click Open) to launch the full 3D CAD workspace.

2. Check-Out Locks & Check-In Revisions

Click Check Out before editing a CAD file to prevent conflicting binary edits. When finished, click Check In v+1 to upload an updated revision while archiving the previous version in Google Drive.

3. Auto-Dimensioned 8.5" × 11" Production PDFs

Click Release on an approved non-COTS part (or Release Folder on a subsystem directory) to auto-generate a 1:1 scale 8.5" × 11" engineering drawing PDF (default tolerance ±1/32 in) in Ready for Production, ordered by subsystem priority.

4. Drawing Revision & Shop Floor Approval

Open any PDF in Ready for Production to inspect dimensions, material, and quantity. Click Revise to add/remove dimensions or upload a manual drawing, and Approve to stamp Checked By and green-light manufacturing.

How Google Drive Storage Works:

• Turso Cloud SQL + Local SQLite: Your Client ID, Target Folder ID, users, projects, locks, and revision notes are stored in your shared Turso SQL database (with a local SQLite mirror) so every teammate sees live updates and GitHub index.html deploys never overwrite data.

• Root Admin Lock: Only Root Admins (such as ryan@frc1310.ca) can modify the OAuth Client ID or Target Google Drive Folder.

• Canonical File Naming & Hidden Revision Archive: The latest revision always keeps the exact original filename in the main subsystem folder. When a new revision is uploaded, the previous file is automatically renamed with its version suffix (e.g., PartName_v1.sldprt) and archived into a hidden .revisions/ folder in Google Drive.
