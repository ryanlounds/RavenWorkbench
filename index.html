Raven Workbench Instructions

Standard operating procedures for FRC Team 1310 CAD version control, locking, and production release.

1. File Explorer & Part Inspection

Navigate subsystem folders in Designs or Ready for Production. Single-click any CAD file to inspect its live 3D quick-preview and metadata; double-click (or click Open) to launch the full 3D CAD workspace.

2. Check-Out Locks & Check-In Revisions

Click Check Out before editing a CAD file to prevent conflicting binary edits. When finished, click Check In v+1 to upload an updated .stl/.obj mesh and release your lock.

3. Releasing to Production

Click Release on an approved part (or Release Folder on a subsystem directory) to publish manufacturing-ready geometry into the Ready for Production explorer.

4. Roles & Subteam Permissions

Only users tagged Design can acquire file locks; Build and Other subteam members have read/inspect access. Mentors manage roles, subteam tags, and external domain approvals.

How Google Drive Storage Works:

• Cloud Database Persistence: Your Client ID, Target Folder ID, users, projects, locks, and revision notes are saved in the cloud database so future GitHub index.html updates never overwrite your data.

• Root Admin Lock: Only Root Admins (such as ryan@frc1310.ca) can modify the OAuth Client ID or Target Google Drive Folder.

• Mirrored Folder Hierarchy: Automatically creates matching Project / Subsystem / Subdirectory folders inside Google Drive when pushing CAD files and native revisions (keepRevisionForever=true).
